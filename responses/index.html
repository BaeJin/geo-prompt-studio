집계 기준

각 비율의 분모는 현재 필터와 분석 기준에 해당하는 전체 응답입니다. 응답마다 분석 한 건을 사용하며, 같은 브랜드·모델이 여러 번 나와도 한 번만 셉니다. 긍정 노출은 선택한 브랜드·모델의 긍정 KBF 평가 수가 부정 KBF 평가 수보다 많은 응답입니다. 동률(0 대 0 포함)은 제외하고 중립 평가는 비교에 넣지 않습니다. 브랜드 전체 선택 시 응답 안의 해당 브랜드 평가를 합산합니다. 긍정 노출과 추천은 독립 지표입니다. 브랜드 전체는 해당 브랜드의 모든 모델과 브랜드 단독 언급을 포함합니다. 특정 모델은 저장된 모델 표기를 기준으로 선택합니다. 미판정은 false로 바꾸지 않고 별도 표시합니다.
